# CHANGELOG

## [1.1.5] - 2026-08-14

### Added
- Проверка обновлений при каждом запуске (не только в веб/print режиме)
- Фоновая проверка здоровья моделей каждые 30 минут на сервере (GET /v1/model-health)
- Кнопка «здоровье» в веб-интерфейсе для просмотра статуса моделей
- Палитра команд включает проверку здоровья моделей (/health)
- Пользовательские системные промты: `/prompt add`, `/prompt use`, `/prompt off`, `/prompt list`
- Отдельный публичный Telegram-бот бесплатно выдаёт один ключ: 100k токенов на 5 часов, автоматический сброс лимита, срок 30 дней

### Changed
- Веб-интерфейс: добавлен чип «здоровье» в шапке с индикатором рабочих/всего моделей
- Недоступные модели возвращают понятное сообщение «технические работы» вместо обрыва запроса
- Остановка запроса больше не показывается как `✗ terminated`
- Обновлён номер версии на 1.1.5

### Fixed
- Исправлен запуск шлюза с фоновой проверкой моделей и проксирование статуса в web-интерфейс

## [1.1.4] - 2026-08-12

### Added
- Внедрён режим `/ssh connect <host>` как внутренний CLI-режим CodeRoom.
- Поддержка `/ssh connect <host> sftp` для открытия SFTP.
- Автоматическая подготовка SSH-ключа и настройка `sshd` при первом подключении.
- Добавлен dynamic prompt для SSH-сессий: `[ssh:<host>]`.

### Fixed
- Исправлена обработка `/ssh connect`, чтобы ввод не выполнялся как простая команда shell.
- Удалён внешний `ssh` shell при `/ssh connect` и заменён внутренней agent-логикой.
- Исправлены ошибки версии и релизные метки.

### Changed
- Обновлён номер версии на `1.1.4`.
- Обновлён `README.md` и `src/config.mjs`.
